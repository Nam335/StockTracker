# StockTracker

Ứng dụng theo dõi giá chứng khoán thời gian thực được xây dựng bằng C++ và Qt Widgets.

## Thành phần

- `Code/Client/StockClient`: ứng dụng Client.
- `Code/Sever/StockServer`: ứng dụng Server.

## Công nghệ

- C++
- Qt 6
- CMake
- TCP Socket

## Mục tiêu

Server phát dữ liệu giá cổ phiếu mô phỏng qua TCP; Client nhận và hiển thị dữ liệu.

## Ghi chú

Đây là dự án học tập. Các thư mục build và cấu hình Qt Creator cục bộ không được đưa vào Git.
